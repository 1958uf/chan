# A股市场状态定位、仓位决策与走势推演 SKILL v2.0（CN版）
> **文件性质**：标准作业程序（SOP）。任何AI接到本文件后，必须严格按规则执行。
> 所有标有【硬规则】的条款为强制约束，违反任何一条即输出无效。
> **本Skill不预测市场。它做四件事：①定位当前资金周期状态；②给出对应仓位区间与加减仓触发信号；
> ③给出概率加权的多情景走势推演（含人物、制度框架的时效校准）；④对不可预测事件只设观察清单与响应规则，禁止臆测。**
>
> **v2.0修订说明**：v1.0实战暴露的最大漏洞是"框架性事实过期"——AI用训练记忆中的旧人物（如已卸任的美联储主席）分析新场景，推理格式完美但前提错误。v2.0新增第1.6节框架性事实核查协议，并将战略层情景推演规则化（第9章），使任何AI产出结构一致、人物引用正确的走势推演。

## 第0章：定位与架构
### 0.1 本Skill解决什么问题
A股与美股的结构性差异，决定了不能直接套用美股框架：
| 维度 | 美股 | A股 | 对分析方法的影响 |
|------|------|-----|----------------|
| 驱动主体 | 机构+回购 | 散户+杠杆资金+政策 | 状态定位比情景概率更可操作 |
| 政策行为者 | 央行主导，路径可推演 | 证监会/汇金/政治局突发性强 | 必须设"不可预测事件"处理协议 |
| 供给端 | 回购收缩股本 | IPO+再融资+解禁持续扩张 | 供给逻辑方向相反 |
| 交易制度 | 无涨跌停 | T+1+涨跌停板 | 跌停阻断流动性出清，负反馈以时间换空间 |
### 0.2 三层决策架构
- **核查层（先于一切）**：框架性事实核查（人物任职/制度框架/政策范式）——v2.0新增
- **战术层（本Skill核心）**：状态机S0-S5 + 五维计分卡 → 周度/日度仓位区间
- **战略层（走势推演）**：情景矩阵 + A股基准率 → 1-6个月概率加权路径推演
- **结合规则**：实际仓位 = 战略中枢 ± 战术偏移，且不得突破战术层区间边界
### 0.3 工作流程（固定顺序，不可跳步）
第0步 声明分析基准日T
→ 第0.5步 框架性事实核查（人物任职/制度框架/政策范式）
→ 第1步 数据获取 → 第2步 置信度与时效分级
→ 第3步 机制链体检（七条链+体制同构性检验）
→ 第4步 五维计分卡 → 第5步 状态机定位（含模糊地带处理）
→ 第6步 仓位区间输出+加减仓触发规则
→ 第7步 观察清单（甲/乙/丙三类事件）
→ 第8步 战略层情景推演（走势预演，按9.3锁定模板）
→ 第9步 按第10章锁定模板输出 → 第10步 质量自检（22项）

## 第1章：数据获取协议（A股版）
### 1.1 数据源优先级
**【硬规则】** 冲突时按优先级取值：
- **P1（官方一手）**：人民银行、证监会、沪深北交易所官网、国家统计局、中证登
- **P2（官方聚合）**：Wind、Choice（若可访问）、外汇交易中心（DR007等）
- **P3（主流媒体数据版）**：证券时报·数据宝、上海证券报、中国证券报、财联社、东方财富
- **P4（券商研报/财经媒体）**：仅用于观点佐证与新闻事实，禁止作为行情数据来源
- **P5（自媒体/财富号/股吧）**：仅可用于线索，**禁止直接作为事实引用**

### 1.3 时效与训练知识禁令
**【硬规则】**
- 分析开始前显式声明"分析基准日 T = YYYY-MM-DD"
- 时效三级：**FRESH**（T日或最近1个交易日/发布周期）/ **RECENT**（2个周期内，阈值需±20%缓冲）/ **STALE**（超2个周期，禁用于现状判断与阈值设定）
- 月度数据超1个月降级；日频数据超3个交易日降级
- **若T日晚于自身训练知识截止日，所有行情数据必须检索获取，禁止用训练记忆冒充当前行情**；检索失败时输出前强制声明"本分析基于训练截止日前数据，仅供框架演示"
- 同一数据点多个来源数值分歧时（如加息概率不同媒体报七成/九成），取更保守值并注明分歧，禁止悄悄选一个
### 1.4 框架性事实核查协议（v2.0核心新增）
**【硬规则】** 行情数据会过期，"框架性事实"同样会过期且更隐蔽——训练记忆中的人物任职、制度机制、政策范式可能已经是旧世界。以下核查先于一切分析执行：
**E1（核查范围——三类框架事实）**：
1. **人物任职状态**：所有将在分析中被具名引用的政策人物（美联储主席、美财长、中国央行/证监会/财政部领导、日本央行行长等）——核实其在T日的实际任职状态
2. **制度框架状态**：点阵图是否存在、FOMC会议频率、北向资金披露机制、涨跌停板制度、披露规则等——核实其T日现状
3. **政策范式状态**：现任决策者的沟通风格（前瞻指引vs沉默式）、监管基调——以其T日前最新公开表态为准
**E2（核查时机）**：声明基准日T之后、构建任何涉及政策行为者的推演之前，必须完成。核查方法：检索"人物名+现任职务"或"制度名+最新状态"。
**E3（人物引用前置校验）**：输出中每提到一个具名政策人物，必须已通过E2核查。若该人物在T日已不在该职位，必须使用正确人物名，并在数据基线表末尾标注"框架事实核查：已完成（美联储主席=T日实际任职者等）"。
**E4（范式适配义务）**：若核查发现制度框架或沟通范式已变化（例如现任主席不做前瞻指引），则所有依赖旧范式的机制链与情景设计必须重新评估，并在情景推演中显式体现——例：在"无前瞻指引"范式下，市场无法从会议声明措辞读出利率路径，相关情景的触发条件应基于"声明实际内容"而非"暗示解读"，且双向不确定性区间应标注更宽。
**E5（高危事实清单——必须逐项核查）**：
| 框架事实 | 过期记忆风险 | 核查方法 |
|---------|-------------|---------|
| 美联储主席是谁 | 训练截止日前的前任 | 检索"现任美联储主席" |
| 美联储沟通范式 | 前瞻指引+点阵图传统 | 检索现任主席最新表态 |
| 美国财长/关键内阁 | 前任 | 检索"现任美国财长" |
| 中国证监会/央行领导 | 前任 | 检索现任名单 |
| 日本央行利率水平与行长 | 负利率时代记忆 | 检索"日本央行政策利率" |
| FOMC会议日历与频率 | 一年8次惯例 | 检索当年官方日历 |
| 北向资金披露机制 | 实时披露旧体制 | 检索交易所现行披露规则 |
**E6（引用连带责任）**：情景推演中触发条件写"某人物讲话释放X信号"时，该人物的任职校验结果必须可追溯至E5核查清单。禁止出现"未核查人物+推测其讲话内容"的组合。

## 第2章：置信度分级
四级：**A**（≥2个P1-P3独立来源一致）/ **B**（单一P1-P2，或2个P3一致）/ **C**（P4推断、P5线索、滞后数据）/ **D**（纯逻辑假设）
**【硬规则】使用权限**：
- A+FRESH：设定触发阈值、支撑结论
- B+FRESH/RECENT：方向判断，阈值须±20%缓冲
- C：仅背景叙述，禁止支撑结论
- D：必须列入"假设清单"单独披露
**实战警示（已发生案例，必须内化）**：
> 自媒体来源曾出现"两融余额1.62万亿"与权威来源"2.63万亿"相差整整1万亿的笔误。P5来源的任何数字必须弃用，只保留定性线索待官方确认。单日高频反转信号（如单日两融回升）在官方周度确认前一律视为噪音，不改变计分。

## 第3章：A股七条核心机制链（含体制同构性检验）
**【硬规则】** 每条链使用前必须完成"体制同构性检验"：该链历史证据产生时的体制变量（人物/披露规则/利率环境/管制松紧/涨跌停制度）与当前是否一致。不一致者自动降为D级。
### 链1：隔夜传导链
隔夜美股/美债收盘 → A50夜盘反应 → A股集合竞价跳空（一次性出清隔夜信息）→ 日内回归本土资金面逻辑 → 14:30后预防性定价当晚海外风险
**实战要点**：跳空缺口方向与日内方向是独立变量，"隔夜大跌→A股必跌"是错误直觉。
### 链2：政策信号多级传导链（A股最强单一催化剂）
政治局/国务院表态（最高级）→ 证监会工具（IPO节奏/再融资/减持规则/两融政策）→ 国家队行动（汇金增持ETF，公告化明牌）→ 官媒定调 → 增量资金入场 → 指数确认
**实战要点**：层级越高信号越强。**政策底从来不等于市场底**（历史时滞1-6个月，具体时点不可预测）。
### 链3：杠杆正反馈（主升期引擎）
指数涨→融资盘盈利→两融增→买盘增→指数更涨（加速）→新开户暴增
### 链4：杠杆负反馈（A股最危险的链）
指数跌破关键位→融资盘触平仓线→强平→跌停（T+1卖不出）→次日继续跌停→流动性螺旋
**断路器（必须写入每个悲观情景）**：①跌停板以时间换空间；②国家队买宽基ETF；③两融连降本身就是缓慢释放——四周连降多为有序出清，需区分"阴跌式出清"（跌停家数不暴增）与"崩塌式出清"（跌停家数暴增）。
### 链5：供给压力链（方向与美股相反！）
IPO+再融资+解禁（日历可预知）→筹码供给扩张→压制整体估值
**体制检验要点**：美股"回购推升慢牛"逻辑禁止移植A股。解禁日历纳入丙类清单。
### 链6：外围流动性链
美联储政策→美债收益率→中美利差→人民币/资本流动压力→央行应对（中间价逆周期/流动性对冲）→A股风险偏好
**体制检验要点**：强度取决于资本管制阀门松紧与人民币实际强弱。**必须用T日实际汇率状态校验**——若人民币强势区间，则"贬值→资本外流→A股失血"强传导不成立，只保留"风险偏好压制"弱传导。
### 链7：风格跷跷板链
风险偏好↑→进攻风格（科技/小盘）强+防御弱；风险偏好↓→反向
**实战要点**：K型分化（防御独涨+普跌，或单一主线独强+普跌）是过渡期/退潮期典型特征，此时期指数失真，**看风格结构不看指数点位做情绪判断**。

## 第4章：政策行为者约束映射（动态任职版）
**【硬规则】** 输出必须含以下主体的"能做/不能做/不愿做"表。**所有主体名单以第1.4节E5核查结果为准**——若某职位已换人，"不愿做"栏必须基于现任者最新公开表态重新填写，禁止沿用前任立场：
| 主体 | 能做 | 不能做 | 信号特征 |
|------|------|--------|---------|
| 政治局/国务院 | 最高级政策定调 | — | 4/7/12月例会+不定期加开，措辞变化是最强催化剂 |
| 证监会 | IPO节奏、再融资、减持规则、两融政策 | 直接印钱、指挥点位 | 突发性极强（周末发文惯例） |

| 人民银行 | 降准降息、MLF/买断式逆回购、中间价引导 | 直接入市 | 通过流动性与汇率间接影响 |
| 海外央行（美联储等） | 政策利率、资产负债表、沟通 | — | **主席沟通风格按E4范式适配：现任者若不做前瞻指引，则"声明解读"传导链强度与前任时代不同，情景设计须体现** |

## 第5章：微观结构检查清单
**【硬规则】** 每次分析必须完成（不可得标N/A并说明影响方向）：
| 检查项 | 来源 | 判读基准 |
|--------|------|---------|
| 两融余额及20日趋势 | 交易所日度 | 连续2周+回升=企稳；连续4周+下降=出清中 |
| 两融占成交额比 | 计算 | 历史极值区>10-11%过热 |
| 涨停/跌停家数、连板高度、炸板率 | 盘后统计 | 跌停>涨停=退潮；连板高度≤3且炸板率>40%=短线资金溃散 |
| 成交额历史分位 | 计算 | <20%分位=地量（双刃：变盘临近但方向不明） |
| 新开户数 | 上交所月度 | 环比暴增=散户进场（S3）；持续回落=退潮 |
| 解禁日历 | 公告汇总 | 未来30日解禁放量=供给压力事件 |
| 期权IV | 交易所 | IV高位+标的阴跌=恐慌未出清 |
| 风格相对强弱 | 指数对比 | 防御独涨或单一主线独强+普跌=K型结构 |
| **主线拥挤度** | 概念指数5日/20日涨幅 | 单一主线20日涨幅>20%且全市场普跌=抱团末期特征（反身性风险） |
**【硬规则】数据矛盾处理**：指标方向矛盾（如两融回升但成交萎缩）时**不得自行调和**，必须如实呈现并计入"状态模糊地带"（见6.4）。

## 第6章：六状态机模型
### 6.1 状态定义
**【硬规则】** 状态判定必须基于可观测硬指标，禁止"感觉市场不行了"式表述：
| 状态 | 名称 | 硬特征（需≥3项同时满足） | 仓位区间 |
|------|------|------------------------|---------|
| **S0** | 极寒期 | 成交额缩至峰值30%以下持续数周；两融连缩>8周；涨停<30家常态；政策已出手但市场无反应 | 0-30%（试探仓） |
| **S1** | 政策确认期 | 重磅政策/汇金增持落地后2-8周；指数仍弱势；两融未回升 | 20-40% |
| **S2** | 启动期 | 放量阳线（成交较地量放大≥50%）；两融连续2周回升；涨停恢复60+且跌停<15 | 40-70%（主加仓区） |
| **S3** | 主升期 | 成交持续高位；两融加速上行；连板高度打开（7板+）；新开户环比暴增 | 70-90%（持有，逢回调加，不追高） |
| **S4** | 过热预警期 | 成交分位>90%；两融增速斜率极端；**监管降温信号**（查配资/IPO提速/官媒警示/特停增多）；连板高度>10或已崩塌 | 40-60%（分批减） |
| **S5** | 退潮期 | 跌停≥涨停；连板高度≤3；两融连降；防御显著跑赢进攻；成交萎缩 | 0-30% |
### 6.2 五维计分卡
**【硬规则】** 每维度-2至+2分，打分必须引用T日FRESH数据：
| 维度 | +2 | +1 | 0 | -1 | -2 |
|------|----|----|---|----|----|

### 6.3 状态迁移确认规则
**【硬规则】**
- **单一信号不迁移状态**：需≥2个独立维度的后续数据确认
- **最短停留期**：状态迁移后至少5个交易日才允许再次迁移
- **降级优先原则**：信号矛盾时向更保守状态偏移
### 6.4 模糊地带处理（诚实核心）
**【硬规则】** 相邻状态无法精确区分时，**必须如实声明模糊，取相邻状态仓位区间的交集下限作为建议**。S0/S1/S5仓位区间刻意重叠（0-40%），使模糊期自动映射到保守仓位——**把"我不知道"转化为"仓位自动变保守"，禁止逼出虚假精确判断**。
