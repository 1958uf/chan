# 缠论策略通俗详解

> 这篇文档用大白话讲清楚缠论引擎到底在算什么、怎么算。尽量不用术语堆砌，能打比方就打比方，但该有的细节一个不少。
>
> 读完你会知道：一根根K线是怎么一步步变成"买点/卖点"信号的。

---

## 0. 先看全景：缠论到底在干什么

想象你看一张股票K线图，肉眼能看出"涨一段、跌一段、再涨一段"的节奏。缠论就是要把这种肉眼感觉，**用规则精确地算出来**，并且层层放大：

```
原始K线  →  合并K线  →  分型  →  笔  →  线段  →  中枢  →  背驰  →  买卖点
```

可以把它想成"望远镜调焦距"：

- **最底层**是每一根K线，太碎了，看不出名堂。
- 往上**合并**掉噪音，找到**转折点**（分型）。
- 把转折点连成**笔**（一段单向运动）。
- 把笔组合成**线段**（一段更大的趋势）。
- 在线段里圈出**中枢**（来回震荡的那个盒子）。
- 看趋势末端是不是**背驰**（涨不动了/跌不动了）。
- 最后在背驰的位置标出**买卖点**。

每一层都是上一层的"放大版"，规则是相通的——这就是缠论常说的"自相似性"。

---

## 1. K线合并：先把"包含关系"清掉

### 1.1 为什么要合并

看下面三根K线：

```
    ┃┃       第二根被第一根完全包住了
   ┃┃┃       这种"你吞我我吞你"的K线，会干扰判断
    ┃
```

如果第二根被第一根完全包含（第一根的最高比第二根高，最低比第二根低），那第二根其实是"废话"，没提供新信息。缠论要求**先把这种包含关系合并掉**，让K线序列干干净净，再去找转折点。

### 1.2 合并的方向感

合并不是简单取平均，而是要**顺着当前趋势**合：

- **上升趋势中**，遇到包含，取"高高、高低"——也就是新的最高 = 两者最高里的大值，新的最低 = 两者最低里的大值。听起来矛盾？其实是为了让合并后的K线"往上飘"。
- **下降趋势中**，反过来，取"低高、低低"——让合并后的K线"往下沉"。

一句话：**趋势向上就往高了合，趋势向下就往低了合**，保证合并不改变原趋势的形态。

### 1.3 怎么判断两根K线的关系

把当前合并K线和下一根新K线比，无非四种情况：

| 两种K线的位置关系 | 说明               | 怎么处理               |
| ----------------- | ------------------ | ---------------------- |
| 旧的完全包住新的  | 新的是"废话"       | 并进旧的               |
| 新的完全包住旧的  | 旧的是"废话"       | 按方向合并进新的       |
| 新的在旧的下方    | 各自独立，趋势往下 | 新起一根，方向记为"下" |
| 新的在旧的上方    | 各自独立，趋势往上 | 新起一根，方向记为"上" |

合并完，新K线的时间结束点更新为最新那根的时间。一字板（开盘=收盘=最高=最低）有特殊保护，不会被乱合。

## 2. 顶底分型：找转折点

### 2.1 什么是分型

合并完K线后，看连续三根，中间那根如果是个"山峰"或"谷底"，就是分型：

- **顶分型**：中间这根，最高价比左右两根都高，最低价也比左右两根都高 → 这是个局部山顶。
- **底分型**：中间这根，最高价比左右两根都低，最低价也比左右两根都低 → 这是个局部谷底。

注意：**高低必须同时满足**。只有最高更高、最低却不够高，不算顶分型——那可能是假山峰。

### 2.2 分型有什么用

分型就是未来的"笔的端点"。就像画折线图，你得先有拐点才能连线。

- 谷底（底分型）开始往上画 → 上升笔
- 山顶（顶分型）开始往下画 → 下降笔

### 2.3 相等价格的细节

有时候两根K线最高价一模一样，算不算顶？在算"特征序列"（后面讲线段会用到）时，规则更细：被包含但顶/底相等时可以选择"不合并"，避免相等价格把分型搞没了。普通K线合并时则正常处理。

## 3. 笔：把转折点连成线

### 3.1 什么是笔

一个顶分型 + 一个底分型，中间那段单向运动，就是一笔。笔是缠论里最小的趋势单元，后面的线段、中枢都靠笔搭起来。

但不是任意两个分型都能连笔，得满足三个条件：

### 3.2 成笔三条件

**条件一：够长（跨度达标）**

两个分型之间得有足够的K线，不然太短没意义。

- 严格模式：中间至少隔4根合并K线（差不多5根以上）。
- 宽松模式：3根合并K线 + 3根原始K线也行。
- 如果中间有跳空缺口，缺口可以"算作一根K线"补进去。

**条件二：分型要"真"（有效性校验）**

防止弱不禁风的假分型混进来。有四档严格度，以顶分型为例：

| 严格度 | 怎么查         | 大白话                                     |
| ------ | -------------- | ------------------------------------------ |
| 最宽   | 只看顶和底两根 | 顶比底高、底的低点比顶的低点低就行         |
| 偏宽   | 看相邻各一根   | 顶要比底旁边两根都高，底要比顶旁边两根都低 |
| 偏严   | 看相邻各两根   | 顶底两侧6根K线一起参与比较                 |
| 最严   | 直接比极值     | 顶的最低点，都要比底那侧的最高点还高       |

底分型反过来对称。默认用"偏严"档——既不太松导致假笔一堆，也不太紧导致漏掉真笔。

**条件三：端点必须是真极值**

从起点分型走到终点分型，中间任何K线都不能"越界"——比如顶分型当起点往下画，中间不能有K线低过终点的最低价。这保证笔的端点确实是这段运动的真正拐点，而不是中途随便挑了个点。

### 3.3 实笔和虚笔（重点理解）

这是缠论处理"最新数据"的聪明之处：

- **实笔**：已经确认结束的笔，板上钉钉。
- **虚笔**：最后一笔还在延伸中，没确认结束。系统会用最新进来的K线试着把这笔的终点往前推。

举个例子：现在有一笔在往下走，还没看到底。新来一根K线创了新低，就把这笔的终点更新到新低（虚笔延伸）。直到某天出现一个底分型，这笔才算"扶正"成实笔，然后从底分型开始新的上升笔。

每次重新计算前，系统会先把虚笔删掉，用之前确认过的终点恢复，避免没确认的数据污染结果。

### 3.4 笔身上有什么

每笔都带着这些属性，后面算背驰、买卖点全靠它们：

- **起点值/终点值**：按方向取（上升笔起点取低、终点取高）。
- **最高/最低/中位价**。
- **振幅**：终点值和起点值的差。
- **力度**：衡量这笔"劲大不大"，可以用MACD面积、峰值、斜率、振幅，甚至成交量、换手率、RSI来算（后面背驰会细讲）。

## 4. 线段：更大的趋势单元

### 4.1 为什么还要有线段

笔太碎了，一会儿上一会儿下。线段是把若干笔组合成"一段更大的、方向明确的趋势"。比如一个上升线段，可能由"涨—小跌—涨—小跌—涨"好几笔组成，但整体往上。

### 4.2 核心招式：特征序列法

这是缠论判定线段结束的标准方法，听着玄，其实就是**"用反向笔当K线，再玩一遍合并+分型"**。

为什么这么做？你想啊，一个上升线段什么时候算结束？当下降笔的力量够大、形成转折的时候。那怎么判断"够大"？就把这些下降笔当成一根根K线来看：

- 上升线段里，反向笔是下降笔 → 把下降笔当K线。
- 对这些"笔K线"做包含合并、找分型，跟K线那套一模一样。
- 一旦在下降笔里找到一个"顶分型"（注意是顶分型，因为对应上升线段的终结），上升线段可能就此结束。

### 4.3 三个元素怎么凑

系统盯着三个"特征元素"（其实就是三根反向笔，可能合并过的）：

1. **第一个元素**：直接放进去。
2. **第二个元素**：试着和第一个合并（相等不合）。合不了就单独成立。但如果它比第一个还低（在上升线段里），说明这俩根本组不成分型，推倒重来。
3. **第三个元素**：和第二个合并判定。然后做两件事：
   - 查"实质突破"：第三个是不是真的突破了第二个？防止合并出假分型。
   - 让第二个跟第一、第三做分型判断。如果第二个成了"顶分型"（上升线段里），线段可能到头了。

### 4.4 真结束还得再确认

光出现分型还不够，得二次确认：

- **有价格缺口**：第二元素和第一元素之间有跳空缺口 → 还得等反向笔也形成分型才算数（递归着找）。
- **没缺口**：得靠"实质突破"确认，不能只是看起来像。

### 4.5 第一段方向怎么定

一开始谁也不知道是上升线段还是下降线段。不能简单看"谁先成分型"（有反例会出错），而是结合"第二元素是否就位"和"当前笔方向"反复试探修正。

### 4.6 剩下的笔怎么办

确定一段线段后，剩下的笔如果不够凑新线段，两种处理：

- **峰值法（默认）**：在剩下笔里找最高/最低点，当作虚拟线段端点。
- **整体法**：把剩下笔整体当一段。

### 4.7 线段的线段

对线段序列再跑一遍线段算法，得到"线段的线段"——比线段更大的趋势级别。同样能算中枢、买卖点。这就是缠论的"级别"概念，一层套一层。

## 5. 中枢：那个来回震荡的盒子

### 5.1 中枢是什么

中枢就是价格在一个区间里来回折腾的区域，代表多空势均力敌。你把它想成一个"盒子"，价格在盒子里上下晃。

缠论定义：**至少3笔（或线段）的价格重叠区间**。

### 5.2 中枢的三个关键

- **盒子上下沿（区间）**：上沿 = 各笔最高价里的最小值，下沿 = 各笔最低价里的最大值。
  - 为什么这么取？因为只有"大家都能接受"的重叠部分才算盒子。你取最高的那个最高价，别的笔够不着，不算；取最低的那个最低价，别的笔也够不着。所以上沿取"最小最高"，下沿取"最大最低"。
- **峰值**：盒子涉及所有笔的真正最高/最低（包括那些伸出盒子的尖刺）。
- **进出笔**：进中枢笔 = 起始笔的前一笔（冲进盒子的那笔）；出中枢笔 = 结束笔的后一笔（冲出盒子的那笔）。

### 5.3 中枢怎么形成

- 默认取最近几笔（一般2笔），如果它们的高低区间有重叠（最小最高 > 最大最低），就成了一个中枢。
- 跨线段算法：至少3笔，可以跨线段构造。
- 第一笔不能直接当中枢起点——必须有"进中枢笔"先冲进来。

### 5.4 中枢会长大

- **延伸**：新来的笔只要还和盒子重叠，就并入中枢，结束笔往后推。中枢可以越震荡越长。
- **合并**：两个相邻中枢如果区间重叠（或峰值区间重叠），就合并成一个更大的中枢，原来的小中枢作为"子中枢"存着。
- 单笔中枢（只有一笔构成）不参与合并，太弱了。

### 5.5 中枢和线段绑定

每个中枢归到它所在的线段里，并记好进/出笔、内部笔列表。线段还会提供：第一个/最后一个"非单笔中枢"、非单笔中枢数量——这些买卖点判定要用（单笔中枢一般不作数）。

## 6. 背驰：趋势末端没劲了

### 6.1 背驰是啥

"背驰"就是趋势走到末端，力量跟不上了。比如上涨，前面那波涨得很猛，现在这波虽然创新高，但力气明显小了——这往往是反转信号。

### 6.2 先过两道关

**第一关：出中枢笔必须突破中枢**

下降笔的最低点要低于中枢下沿，或上升笔的最高点要高于中枢上沿。连盒子都没冲出去，谈不上背驰。

**第二关：比进出的力度**

算两笔的力度：

- 进中枢笔的力度（冲进盒子那笔多猛）
- 出中枢笔的力度（冲出盒子那笔多猛，从终点往起点算）

### 6.3 力度怎么算

力度可以用很多指标衡量，随你选：

| 算法             | 大白话                                       |
| ---------------- | -------------------------------------------- |
| 半边面积         | MACD红绿柱（同方向的）加起来，遇到反方向就停 |
| 整笔面积         | 整笔同向MACD柱的总面积                       |
| 峰值（笔默认）   | 同向MACD柱里最大那根的绝对值                 |
| 差值             | MACD柱最大值减最小值                         |
| 斜率（线段默认） | 平均每根K线涨/跌多少                         |
| 振幅             | 价格波动幅度                                 |
| 量能类           | 成交量/成交额/换手率（可取平均）             |
| RSI              | RSI的极值                                    |

### 6.4 怎么判背驰

- **保送模式**（阈值设极大）：只要出中枢笔突破就判背驰。
- **正常模式**：出中枢力度 ≤ 阈值 × 进中枢力度，就算背驰。
- 力度比（出/进）小于1，说明出中枢比进中枢还弱，标准背驰，反转概率高。

### 6.5 盘整背驰（没标准中枢时）

有时候没形成标准中枢，但同一线段里相隔一笔的两笔可以比：当前这笔没创新低/新高，力度却比前一笔小 → 这叫盘整背驰，对应后面的1p类买卖点。

## 7. 买卖点：该出手的位置

### 7.1 方向约定

- **下降笔末端 = 买点**（跌完了该买了）
- **上升笔末端 = 卖点**（涨完了该卖了）

买、卖两套参数可以分别调。

### 7.2 六种买卖点

这是缠论最实用的部分。每一类都对应一种特定的市场结构：

| 类型           | 是什么               | 怎么判定                                                                                     |
| -------------- | -------------------- | -------------------------------------------------------------------------------------------- |
| **1类**  | 趋势反转点           | 线段最后一个中枢背驰了 + 出中枢笔突破 + 出中枢笔是极值。这是抓大顶大底的点。                 |
| **1p类** | 盘整背驰点           | 没标准中枢时，同线段相邻同向笔力度衰竭 + 不创新极值。比1类弱，但也是转折信号。               |
| **2类**  | 反转后首次回抽       | 1类点出现后，第2笔回抽，回抽幅度别太大（≤设定的最大回抽比例）。这是"确认反转"的二次进场点。 |
| **2s类** | 中枢震荡里的多次回抽 | 在2类基础上，沿着同方向笔一直延伸，每笔和前笔区间重叠、且不破1类前的极值。震荡市里能反复做。 |
| **3a类** | 中枢在1类之后        | 下一个线段首个中枢被突破后的反抽笔，不回中枢、可破中枢峰值。这是"突破回踩"的买点。           |
| **3b类** | 中枢在1类之前        | 本线段最后一个中枢之后、1类之前的同向笔，不回中枢。这是"中继加速"的点。                      |

记忆口诀：

- **1类抓反转**（背驰转折）
- **2类抓回抽**（反转后第一次回踩确认）
- **3类抓突破**（中枢突破后的回踩，分a中枢在后、b中枢在前）

### 7.3 关键参数（可以调的旋钮）

| 参数                     | 作用                                     |
| ------------------------ | ---------------------------------------- |
| 背驰力度比阈值           | 调背驰严不严，设极大就是"只要突破就背驰" |
| 1类最少中枢数            | 1类点至少要几个中枢打底                  |
| 1类只认多笔中枢          | 单笔中枢算不算数（默认不算）             |
| 1类出中枢笔为极值        | 出中枢那笔必须是极值才认                 |
| 2类最大回抽比例          | 2类回抽最多回多少（≤1，默认0.9999）     |
| 2类/3类跟随1类           | 2类、3类必须先有1类才认                  |
| 类二跟随2类 / 最大层级   | 2s类要不要跟着2类、最多延伸几层          |
| 3类严格度 / 3a中枢数上限 | 3类严不严、3a最多认几个中枢              |
| 力度算法                 | 笔层默认用峰值，线段层默认用斜率         |
| 启用类型                 | 想要哪几种，如 "1,1p,2,2s,3a,3b"         |

### 7.4 怎么避免反复计算

- 系统记着"最后一个确定线段"的位置，每次只重算这之后的部分，不全量重算。
- 落在不确定区域的买卖点会被清掉，对应笔的标记也清空，防止脏数据。
- 同一笔可能同时是好几种买卖点（比如又是1类又是别的），系统会叠加标记，并记住它关联的1类点。

### 7.5 每个买卖点带着啥

每个买卖点都附一组特征值：笔振幅、背驰比、中枢数、回抽比、中枢高度比等。这些可以喂给后面的选股、回测、策略组合用。

## 8. 多级别：大级别看方向，小级别找点位

### 8.1 为什么要多级别

单看一个级别（比如只看日线）往往不够准。缠论习惯**大级别定方向、小级别定点位**：日线看到背驰了，再去60分钟找精确的1类买卖点进场。

### 8.2 怎么联动

- 级别从大到小排（如 日线 → 60分钟），强制校验顺序。
- 大级别每根K线，会触发小级别一轮计算，建立"父子K线"关系，形成树状结构。
- 父子级别会做时间一致性、对齐检查，对不上就报警，超过阈值直接报错。
- 多级别**不改变**单级别的算法，只是提供组合视角：大级别背驰 + 小级别1类 = 更可靠的信号。

---

## 9. 默认配置一览

新手不用动这些，但得知道默认怎么设的：

| 模块   | 默认行为                                                                |
| ------ | ----------------------------------------------------------------------- |
| 笔     | 严格模式、偏严分型校验、不把缺口当K线、端点必须是极值、允许次高低点成笔 |
| 线段   | 特征序列法、剩余笔用峰值法处理                                          |
| 中枢   | 允许合并、按区间合并、不要单笔中枢、默认算法                            |
| 买卖点 | 六类全开、笔层用峰值算力度                                              |
| 背驰   | 阈值极大（保送）、1类至少1个中枢、只认多笔中枢                          |
| 2类    | 最大回抽0.9999、1类出中枢笔必须是极值                                   |
| MACD   | 12/26/9 标准参数                                                        |

> 线段层面的买卖点会覆盖两个设置：力度算法改用斜率、不要求多笔中枢。也就是说，线段层用斜率衡量力度、对中枢结构更宽松。

## 10. 一句话总结整套逻辑

缠论引擎干的事，可以归纳成七步心法：

1. **去噪**：合并包含关系、校验分型，把K线里的废话和假转折清掉。
2. **找拐点**：在干净K线上识别顶底分型。
3. **连线**：把拐点连成笔，笔是最小趋势单元。
4. **组大趋势**：用特征序列法（反向笔当K线再玩一遍合并+分型）把笔组成线段。
5. **圈震荡区**：在线段里圈出中枢（多空均衡的盒子）。
6. **看衰竭**：比较进/出中枢两笔的力度，判断背驰（趋势没劲了）。
7. **标点位**：在背驰和结构位置标出1/1p/2/2s/3a/3b六类买卖点。

再加上**多级别互证**：大级别看方向，小级别找点位，互相印证。

核心思想一句话：**结构层层递进，力度决定转折**。价格运动的形态在不同级别上自相似，而每一次反转都伴随力度的衰竭——缠论就是用规则把这两件事精确算出来。
