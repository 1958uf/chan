# 缠论策略业务逻辑说明

> 本文档仅阐述缠论引擎的业务逻辑与算法思路，不涉及具体代码实现细节。
> 目标：用简洁、结构化的方式说清"K线合并 → 分型 → 笔 → 线段 → 中枢 → 背驰 → 买卖点"这条完整链路每一步到底怎么算。

---

## 0. 总览：处理流水线

整套缠论分析按以下顺序逐层推导，前一步的输出是后一步的原料：

```
原始K线
   │  ① 包含关系合并
   ▼
合并K线
   │  ② 顶底分型识别
   ▼
分型（顶 / 底）
   │  ③ 分型有效性校验 + 笔跨度校验
   ▼
笔
   │  ④ 特征序列 + 特征序列分型
   ▼
线段
   │  ⑤ 至少3笔重叠区间
   ▼
中枢
   │  ⑥ 进出中枢两笔力度比较
   ▼
背驰判定
   │  ⑦ 1/1p/2/2s/3a/3b 买卖点
   ▼
买卖点
```

数据结构层层嵌套：原始K线合并成"合并K线"，合并K线的分型端点连成"笔"，笔组合成"线段"，线段可再组合成"线段的线段"（更高一层趋势）；中枢和买卖点则可分别建立在笔、线段两个层面上。每个时间级别（如日线、60分钟）都独立维护一整套上述结构，级别之间通过父子K线关系联动。

---

## 1. K线合并（处理包含关系）

**目的**：相邻K线若存在包含关系（一根完全吞噬另一根的高低范围），会干扰分型识别，必须先合并掉，使合并后的K线序列不再有任何包含关系。

### 1.1 方向决定合并取值

合并K线带有方向（上升或下降），方向由前一根合并K线的趋势决定，并决定被包含时取大还是取小：

- **上升方向**：取高高、取高低 → 新的 high = max(两者high)，新的 low = max(两者low)
- **下降方向**：取低高、取低低 → 新的 high = min(两者high)，新的 low = min(两者low)

这样保证合并后的K线"顺趋势"延伸，不会反向吞噬、改变原有趋势形态。

### 1.2 包含关系判定

比较当前合并K线 `(high, low)` 与待加入K线 `(high, low)`，分四种情况：

| 关系 | 含义 | 处理 |
|------|------|------|
| 旧K线完全包含新K线（旧high≥新high 且 旧low≤新low） | 新被旧吞 | 并入旧K线 |
| 新K线完全包含旧K线（旧high≤新high 且 旧low≥新low） | 旧被新吞 | 按方向合并 |
| 新K线在旧K线下方（旧high>新high 且 旧low>新low） | 不包含 | 新起一根，方向向下 |
| 新K线在旧K线上方（旧high<新high 且 旧low<新low） | 不包含 | 新起一根，方向向上 |

### 1.3 合并动作

- 判定为包含关系时：把新K线并入当前合并K线，按方向重算 high/low，结束时间更新为新K线的时间。
- 判定为不包含时：新起一根合并K线，方向由其相对位置决定，并对倒数第二根合并K线做分型识别。

> 一字K线（high==low）有特殊保护，避免被误合并。

---

## 2. 顶底分型识别

**目的**：在不含包含关系的合并K线序列上，识别局部极值点，作为笔的端点候选。

### 2.1 判定规则

取连续三根合并K线，设中间一根为 self，前后分别为 pre、next：

- **顶分型**：中间K线的 high 比 pre、next 都高，且 low 也比 pre、next 都高 → 局部最高点。
- **底分型**：中间K线的 high 比 pre、next 都低，且 low 也比 pre、next 都低 → 局部最低点。

即中间K线的高低都要同时比两侧都高（顶）或都低（底），缺一不可。

### 2.2 相等边界的精细处理

在特征序列合并场景下，允许"被包含但顶/底相等时不合并"，通过参数精细控制相等边界的归属，避免相等价格导致分型误判。

### 2.3 分型是笔的原料

只有顶分型、底分型才能成为笔的端点。笔的方向由起始分型决定：

- 起点为底分型 → 上升笔
- 起点为顶分型 → 下降笔

---

## 3. 笔的生成

**目的**：把相邻的顶底分型连成一段单向运动。笔是缠论中最小的趋势单元，也是线段、中枢的构建基础。

### 3.1 成笔三条件

两个分型（一顶一底）之间能否连成一笔，需同时满足：

1. **跨度条件**
   - 严格模式：两分型之间合并K线数 ≥ 4（即至少5根合并K线，含至少3根独立K线）。
   - 非严格模式：合并K线数 ≥ 3 且原始K线数 ≥ 3。
   - 若开启"缺口视作K线"，相邻K线间存在跳空缺口时，跨度额外 +1。
2. **分型有效性**：防止"假分型"成笔（见 §3.2）。
3. **端点为极值**：从起点分型到终点分型之间，没有任何K线越过起点的极值——即顶分型起点到终点之间，中间K线的 high 不超过终点的 high；底分型对称。这保证笔的端点确实是这段运动的真正极值。

### 3.2 分型有效性校验

为防止力度不足的假分型成笔，提供4种校验力度，以顶分型为例：

| 力度 | 比较范围 | 顶分型校验 |
|------|----------|------------|
| 最宽 | 只看顶底两根 | 顶的 high > 底的 high，且 底的 low < 顶的 low |
| 偏宽 | 看相邻各一根 | 顶的 high > 底侧相邻两根的最高值，且 底的 low < 顶侧相邻两根的最低值 |
| 偏严 | 看相邻各两根 | 顶底两侧共6根参与比较 |
| 最严 | 极值比较 | 顶的最低点都高于底侧最高点 |

底分型对称。力度越严，假分型越难成笔，笔越少越可靠；力度越宽，笔越多越敏感。默认采用偏严档。

### 3.3 实笔与虚笔

- **实笔**：已确认结束的笔。
- **虚笔**：当前正在延伸、尚未确认结束的最后一笔。系统会用最新K线尝试延伸最后一笔的终点；一旦出现反向分型，就把虚笔"扶正"为实笔，并从该分型开始新的反向笔。
- 每次重算前会先删除虚笔，用历史确认终点恢复或重建，避免未确认数据污染后续计算。
- 当不允许"次高低点成笔"时，若最后一笔的端点能取到更极端的值，会更新端点。

### 3.4 笔的属性

- 起点值/终点值：按方向取——上升笔起点取低、终点取高；下降笔起点取高、终点取低。
- 笔的最高/最低/中位价。
- 笔振幅 = |终点值 - 起点值|。
- 力度指标：用于背驰比较，支持 MACD 面积/峰值/斜率/振幅，以及成交量、成交额、换手率、RSI 等多种算法（见 §6.2）。

---

## 4. 线段的生成（特征序列法）

**目的**：笔只是局部运动，线段才是有意义的趋势单元。线段由若干笔组成，代表一个方向上的完整推进。

### 4.1 特征序列定义

线段由笔构成。**特征序列法**的核心思想：把"与线段方向相反的笔"当作K线，套用 K线合并 + 分型 那一套来判定线段何时结束。

- 上升线段中，反向笔是下降笔 → 用下降笔构造特征序列。
- 对这些反向笔做包含合并与分型识别，方法和K线完全一致。
- 系统维护特征序列的3个元素，目标是找中间那个元素（第二元素）的顶/底分型。

### 4.2 三元素逐步填充

对每根反向笔依次处理：

1. **第一元素**：直接放入。
2. **第二元素**：尝试与第一元素做包含合并（相等不合并）。若不能合并则新建为第二元素。若前两元素的高低关系注定无法形成分型（如上升线段中第二元素比第一元素还低），则推倒重来。
3. **第三元素**：与第二元素做合并判定。然后：
   - 检查第三元素是否对第二元素有"实质突破"，防止因合并导致看似分型实则无真实突破的伪信号。
   - 让第二元素与第一、第三元素做分型识别。
   - 若第二元素形成与线段方向一致的分型（上升线段→顶分型），则线段可能在此结束。

### 4.3 线段结束确认

特征序列分型出现后，还要二次确认：

- **有价格缺口**：第二元素是分型，且与第一元素之间存在价格缺口 → 需要反向笔也形成分型才算确认（递归寻找反向特征序列分型）。
- **无缺口**：依赖实质突破标志，需实际突破确认。

分型对应的极值笔索引 = 分型高点/低点对应的笔的前一根。

### 4.4 第一段方向判定

不简单以"哪个方向先成分型"来定第一段方向（这会导致某些反例误判），而是结合"第二元素是否就位"与"当前笔方向"反复修正候选方向。

### 4.5 左侧剩余笔处理

确定线段之后，若剩余的笔不足以形成新线段，按策略处理：

- **峰值法（默认）**：在剩余笔中找最高/最低点作为虚拟线段端点。
- **整体法**：把剩余笔整体当作一段虚拟线段。

### 4.6 线段的线段

对线段序列再跑一遍线段算法，得到"线段的线段"——比线段更高一层的趋势级别，同样可以算中枢和买卖点。

---

## 5. 中枢的生成

**目的**：中枢是价格反复震荡的重叠区间，代表多空力量均衡的区域，是判断背驰和买卖点的核心参照。

### 5.1 中枢三要素

- **区间（low / high）**：中枢的价格重叠带 = max(各笔最低) ~ min(各笔最高)。下沿取所有笔最低中的最大值，上沿取所有笔最高中的最小值——只有重叠的部分才算中枢。
- **峰值（peak_low / peak_high）**：中枢涉及所有笔的真正最低/最高值（含未重叠的尖刺）。
- **起止笔**：中枢的起始笔与结束笔；进中枢笔 = 起始笔的前一笔；出中枢笔 = 结束笔的后一笔。

### 5.2 构造逻辑

- 默认算法：取最近若干笔（通常2笔，非单笔中枢模式），若这些笔的高低区间有重叠（即 min(各high) > max(各low)）则成一个中枢。
- 跨线段算法：需要至少3笔，且允许跨线段构造。
- 禁止第一笔就是中枢起点（必须有"进中枢笔"）。

### 5.3 延伸与合并

- **延伸**：新笔若与中枢区间重叠，则并入中枢，更新结束笔。中枢可以随震荡不断延伸。
- **合并**：相邻中枢若区间重叠（按区间合并模式）或峰值区间重叠（按峰值合并模式），则合并成一个更大的中枢，原中枢作为子中枢保留。
- 单笔中枢不参与合并。

### 5.4 中枢与线段绑定

把每个中枢归入所属线段，并设置进/出中枢笔及中枢内部笔列表。线段层面提供：
- 首个/末个非单笔中枢。
- 非单笔中枢数量（买卖点判定要用，单笔中枢通常不算）。

---

## 6. 背驰判定

**目的**：背驰指趋势末端力度衰竭，是判断趋势反转的关键信号。

### 6.1 前置条件

1. 出中枢笔必须突破中枢区间——下降笔的最低点低于中枢下沿，或上升笔的最高点高于中枢上沿。不突破则谈不上背驰。
2. 计算进中枢力度与出中枢力度（出中枢力度从终点向起点累积，方向相反）。

### 6.2 力度算法

力度指标决定如何量化一笔的"力量"，可选算法：

| 算法 | 含义 |
|------|------|
| 半边面积 | 同号MACD柱累加，遇反号即停 |
| 整笔面积 | 整笔同向MACD柱面积 |
| 峰值（笔默认） | 同向MACD柱最大绝对值 |
| 差值 | MACD柱最大值减最小值 |
| 斜率（线段默认） | 单位K线价格变化率 |
| 振幅 | 价格振幅 |
| 量能类 | 成交量/成交额/换手率（可取均值） |
| RSI | RSI极值 |

### 6.3 背驰结论

- 阈值设为极大（保送模式）：只要出中枢笔突破即判背驰，返回力度比。
- 正常模式：出中枢力度 ≤ 阈值 × 进中枢力度 即判背驰。
- 力度比 < 1 表示出中枢力度小于进中枢力度 → 标准背驰，反转概率高。

### 6.4 盘整背驰

无标准中枢时，比较同线段内相隔一笔的两笔力度：当前笔不创新低/新高 + 力度小于前笔 → 盘整背驰，对应 1p 类买卖点。

---

## 7. 买卖点定义

**目的**：在背驰与中枢结构基础上，标记出值得交易的位置。依次计算 1类 → 2类 → 3类，并分笔层面、线段层面两套独立计算。

### 7.1 方向约定

下降笔末端是买点（做多），上升笔末端是卖点（做空）。买、卖两套参数独立配置。

### 7.2 买卖点类型

| 类型 | 含义 | 判定要点 |
|------|------|----------|
| **1类** | 趋势背驰转折点 | 线段最后一个中枢背驰 + 出中枢笔突破 + 出中枢笔是极值 |
| **1p类** | 盘整背驰 | 无标准中枢时，同线段相邻同向笔力度衰竭 + 不创新极值 |
| **2类** | 趋势转折后首次回抽 | 1类笔之后的第2笔，回抽幅度 ≤ 最大回抽比例 |
| **2s类** | 类二（中枢震荡中多次回抽） | 在2类基础上沿同向笔延伸，每笔与前笔区间重叠且不破1类前的极值 |
| **3a类** | 中枢在1类之后 | 下一线段首个中枢突破后的反抽笔，不回中枢、可破中枢峰值 |
| **3b类** | 中枢在1类之前 | 本线段末个中枢之后、1类之前的同向笔，不回中枢 |

### 7.3 关键参数

| 参数 | 作用 |
|------|------|
| 背驰力度比阈值 | 控制背驰严格度，极大=保送 |
| 1类最少中枢数 | 1类所需最少中枢数量 |
| 1类只认多笔中枢 | 1类是否排除单笔中枢 |
| 1类出中枢笔为极值 | 出中枢笔是否必须是极值 |
| 2类最大回抽比例 | 2类允许的最大回抽幅度（≤1） |
| 2类/3类跟随1类 | 2类/3类是否必须依赖已存在的1类 |
| 类二跟随2类 / 类二最大层级 | 类二是否跟随2类、最大延伸层级 |
| 3类严格度 / 3a中枢数上限 | 3类严格度与中枢数上限 |
| 力度算法 | 笔层面默认峰值，线段层面默认斜率 |
| 启用类型 | 如 "1,1p,2,2s,3a,3b" |

### 7.4 增量计算与失效

- 系统记录最后一个确定线段的位置，每次只重算其之后的部分，避免全量重算。
- 位于不确定区域的买卖点会被清除，并把对应笔的标记置空，避免脏数据。
- 同一笔可叠加多个买卖点类型，并记录其关联的1类买卖点。

### 7.5 特征输出

每个买卖点附带一组特征值：笔振幅、背驰比、中枢数、回抽比、中枢高度比等，供下游选股、回测、策略组合使用。

---

## 8. 多级别联动

- 级别列表从大到小排列（如 日线 → 60分钟），强制校验顺序。
- 高级别每根K线触发次级别迭代，建立父子K线关系，形成多级别树状结构。
- 父子级别做时间一致性、对齐校验，超阈值报错。
- 多级别本身不改变单级别算法，而是提供"大级别背驰 + 小级别1类"这类组合验证视角，互相印证提高可靠性。

---

## 9. 默认配置速查

| 模块 | 参数 | 默认值 |
|------|------|--------|
| 笔 | 严格模式 / 分型校验 | 严格 / 偏严档 |
| 笔 | 缺口视作K线 / 端点为极值 / 允许次高低点 | 否 / 是 / 是 |
| 线段 | 算法 / 左侧剩余处理 | 特征序列法 / 峰值法 |
| 中枢 | 合并 / 合并模式 / 单笔中枢 / 算法 | 是 / 区间 / 否 / 默认 |
| 买卖点 | 启用类型 / 力度算法 | 1,1p,2,2s,3a,3b / 峰值 |
| 买卖点 | 背驰阈值 / 最少中枢数 / 只认多笔中枢 | 极大 / 1 / 是 |
| 买卖点 | 2类最大回抽 / 1类出中枢为极值 | 0.9999 / 是 |
| MACD | 快/慢/信号周期 | 12/26/9 |

> 线段层面买卖点覆盖：力度算法用斜率，不要求多笔中枢——即线段层用斜率衡量力度、对中枢结构要求更宽松。

## 10. 核心思路总结

整套缠论引擎的本质是**层级化结构识别 + 力度衰竭判断**：

1. **去伪存真**：合并包含关系、校验分型有效性，消除噪音，留下真实极值。
2. **层层递进**：K线 → 分型 → 笔 → 线段 → 中枢，每一层都是上一层的有意义组合，而非简单聚合。
3. **特征序列复用**：线段判定复用K线合并+分型那套方法，只是把"反向笔"当K线，体现了缠论的自相似性。
4. **中枢即均衡**：中枢刻画多空均衡区，突破与回踩都相对中枢定义。
5. **背驰即衰竭**：通过进出中枢两笔的力度对比，判断趋势是否末端衰竭。
6. **买卖点即结构位置**：1类抓反转、2类抓回抽确认、3类抓中枢突破回踩，各有明确的结构定义。
7. **多级别互证**：不同级别独立计算又通过父子关系联动，大级别定方向、小级别定点位。
