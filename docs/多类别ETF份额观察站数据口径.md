# 多类别ETF份额观察站：数据口径

## 功能说明

新系统以基金**日份额**为核心：目录分类、同类产品对比、日/周/月历史和自动日更。价格、NAV估算流量与盘中研究评分只作为辅助，不阻塞日份额统计。

## 参数说明

- `as_of`：统一统计截止日期。类别总量必须使用同一实际统计日，不混用每只基金各自最新日期。
- `period`：day/week/month，表示与上一个对应期末的可比变化。
- `frequency`：day/week/month，历史显示按期末存量重采样，不相加日存量。
- `asset_class`：宽基、行业、主题、风格、债券、商品、跨境、货币或未分类。
- `classification_status`：confirmed、candidate、unclassified；名称匹配只作候选，确认需代码/指数证据或用户人工核对。
- `coverage`：同时展示目录发现、分类确认、当前日有效、首尾可比成员数量；一个百分比不能替代所有覆盖。
- 单位：存储为份，显示亿份须除1e8；不是元或亿元。

## 汇总示例

```text
类别含A、B、C三只ETF：
A前日100份、当日120份；B前日200份、当日190份；C当日50份但缺前日。

当日总份额=360份（3只当日有值）。
可比成员=A/B，净变化=+20-10=+10份。
可比基线=100+200=300份，变化率=10/300≈3.33%。
C不能凭新增50份当作净申购。
```

若A发生拆分或中间缺交易日，其变动需标疑点或不可比；总量展示可以带质量说明，但不能混入可靠申赎变化。

## 必须保留的限制

- 同指数不同ETF面值和拆分历史不同，原始份额合计不代表投资金额；可比变化只是在固定集合下的份额指标。
- 上市、退出、目录发现及分类变更会改变成员范围，应单独显示，不当资金流。
- 日频份额通常滞后，日更新不是实时申赎。
- 国家队通过场内买入存量ETF可能不改变份额，其他投资者也会申赎；本系统不确认账户身份。
- PIT本地已知版本与事后历史分开；目录未来分类不能偷偷回写成过去当时已知。

## 验收重点

分类冲突、人工覆盖保留、目录分页/来源失败、同日聚合、可比集合、上市退出、断档拆分、周月末日期、5/20交易日历史不足、纯份额任务无价格依赖、日更幂等/取消/失败重试、真实两市单位日期及前端对应页面。
