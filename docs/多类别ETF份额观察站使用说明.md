# 多类别ETF份额观察站使用说明

## 功能说明

本轮把独立系统的主线改为多类别ETF日份额：产品目录、分类、同类产品、同日总份额、可比净变化、日/周/月历史与份额日更。原精选观察池和行情详情保留辅助，不再用盘中刷新或NAV估算阻塞份额主线。

### 产品目录与精选池

- 目录来自沪深公开清单，支持搜索、资产大类、指数分组、候选/确认状态和来源覆盖。
- 精选池仍是原有少量重点ETF，不能当全市场目录。
- 名称推断为候选，不能把所有“300”“50”或“红利”混在同一个指数。
- 人工确认后保留用户配置，同步目录不覆盖人工分类和停用。

## 参数说明

| 参数 | 用途 |
|---|---|
| `as_of` | 统一统计日，实际份额披露有延迟；不同日期不能直接混合总量 |
| `period` | day/week/month，与对应上一期末比较 |
| `frequency` | 份额历史按日/周/月期末存量，不相加日存量 |
| `asset_class` | 宽基/行业/主题/风格/债券/商品/跨境/货币/未分类 |
| `classification_status` | confirmed/candidate/unclassified，确认需证据或人工核对 |
| `daily_update_hour/minute` | 日份额调度时间；默认18:17，失败和下一发布日需核对 |
| `intraday_enabled` | 默认false，盘中功能降为可选辅助 |

## 使用示例

启动方式继续兼容：

```powershell
# 从主工程根目录执行。
& ./extension/etf_monitor/scripts/start.ps1 -Mode demo
& ./extension/etf_monitor/scripts/start.ps1 -Mode live
# 检查目录/份额来源后再开启日更。
& ./extension/etf_monitor/scripts/start.ps1 -Mode live -Schedule
```

页面建议流程：

1. 产品目录中同步沪深清单，先看每市来源是否成功；记录数不等于已分类数。
2. 查看核心指数成员和候选，人工确认真实所属类别；未确认不混入已确认总体。
3. 创建纯份额更新任务，按类别或代码采集短日期区间，不默认抓价格/NAV/分钟。
4. 首页查看同一统计日类别总份额、可比份额增减、增加/减少/缺失成员及覆盖。
5. 打开类别详情，对比同类产品；按日/周/月查看期末份额和变化。
6. 按需历史补采，下载CSV/JSON或图表PNG，保留日期、来源和质量。

API示例（GET只读）：

```text
GET /api/catalogue?asset_class=宽基&classification_status=confirmed
GET /api/shares/overview?as_of=2026-10-28&period=day
GET /api/shares/groups/沪深300?as_of=2026-10-28&period=week
GET /api/shares/history?group=创业板&start=2026-09-01&end=2026-10-28&frequency=month
```

任务及人工分类为变更API，需沿用本地Origin和会话令牌，不能通过任意外部网页触发采集。

## 口径与可靠性

- 份额为基金存量不是国家队总持仓，变化包含所有投资者申赎。
- 类别变化使用前后都存在的同一可比集合；新产品、退出、缺失、拆分和分类变更分开。
- 份额存储单位份，界面显示亿份；不是资金金额。
- 周/月看期末和上一期末，不把每天存量相加。
- 缺日历、窗口基线、分类证据或源返回时明确未知，不补零。
- 目录只有最新清单时不能当历史目录；未来新产品不能自动回写成过去当时已知。
- 测试、真实数据抽查及剩余限制以本轮可靠性验收报告为准，使用前检查实际最新日期。
